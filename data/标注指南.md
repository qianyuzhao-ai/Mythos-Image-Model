# 4 张电影质感试训图怎么标注

把 4 张图直接放进 `data/smoke/`，可用 JPG、JPEG、PNG 或 WebP。每张图配一个同名的 UTF-8 纯文本文件，例如 `01.jpg` 配 `01.txt`，`02.png` 配 `02.txt`。每条标注以 `mythoscine，` 开头，后面写实际画面。

训练图片和标注只保存在本地。新克隆仓库后，在放图时一起创建对应的 `.txt` 文件。这台已配置的 Mac 上可以直接填写现有的 `01.txt` 至 `04.txt`。

**每张写一两句。** 写清谁或什么在画面里、在做什么、景别是什么、主光从哪里来。想在生成时改变的条件可以明说，比如白天、雨夜、侧光或远景。下面四句展示写法，填自己的文件时以图里实际可见的内容为准。

| 示例配对 | 示例标注 |
| --- | --- |
| `01.jpg` ↔ `01.txt` | mythoscine，日间室内，中景。一个人坐在木桌边拆信，左侧窗光照亮脸颊，身后的书架在暗处。 |
| `02.png` ↔ `02.txt` | mythoscine，白天的山路，远景。行人背对镜头经过石桥，薄云遮住太阳，远处的树仍清晰可见。 |
| `03.jpg` ↔ `03.txt` | mythoscine，夜间室内，近景。一双手在暖色台灯下修表，表壳有一道反光，背景落在暗处。 |
| `04.jpg` ↔ `04.txt` | mythoscine，夜间街道，全景。骑车人从画面右侧经过，湿路面映着店铺招牌的红光。 |

如果素材允许，挑一张日内、一张日外、一张夜内、一张夜外，顺带覆盖近景和全景。优先挑四个独立镜头，在副本上裁掉视频黑边、字幕或台标，保留有效画面的比例。训练器会按配置缩放，原图可以大于 512 像素。
